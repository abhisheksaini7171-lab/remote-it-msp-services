
# Security Policy

Thank you for helping keep Remote IT & MSP Services and its users safe.

## Supported Projects

This repository contains the public website for Remote IT & MSP Services.

Security reports concerning the website, its source code, or repository configuration are welcome.

## Reporting a Vulnerability

If you discover a potential security vulnerability, please report it privately.

**Security contact:** abhisheksaini7171@gmail.com

Please include:

- A description of the suspected vulnerability.
- The affected page, file, or component.
- Steps to reproduce the issue.
- Potential impact.
- Supporting screenshots or evidence, if available.

Please do not include passwords, API keys, access tokens, or other sensitive information in your report.

## Responsible Disclosure

- Please do not publicly disclose a vulnerability before coordinating with us.
- Do not access, modify, or download other people's data.
- Do not disrupt website availability or services.
- Do not perform destructive testing or social engineering.
- Only test systems and resources you are authorized to access.

## Response and Remediation

We will review reports and make reasonable efforts to investigate valid security concerns.

Response and remediation timelines will depend on the severity and complexity of the issue.

## Scope

This policy covers the public website and this GitHub repository.

Third-party platforms and services, including GitHub Pages, Cloudflare, email providers, and external integrations, are governed by their respective security reporting policies.
